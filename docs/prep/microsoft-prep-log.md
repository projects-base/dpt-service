## Problem log

Format — one line, same day:

```
DATE | PROBLEM | PATTERN | TIME | OUTCOME | INSIGHT
```

`OUTCOME` is one of: `SOLVED` · `SOLVED-hint` · `EDITORIAL` · `FAILED`.
Never `FAILED` with a blank insight — what you didn't see *is* the insight.

```
2026-09-21 | 1. Two Sum | arrays-hashing | 6m | SOLVED | store complement not value; one pass is enough
```

## Review queue (+3 / +10 / +30)

memory, check against your logged insight. Full re-solve only if you fail step one — and then it
re-enters at +3.
